# Parasite Eve Beta 0.2.0 (Build 12)

Parasite Eve 1&2 Port community: https://discord.gg/Yg88tHYXK

Based heavily on khasinski/parasite-eve-pc.

Native PS5 homebrew beta requiring user-supplied compatible game data. No discs, private texture packs, saves or personal settings are included.

## Build 12 changes
- Updated final owner-selected P5 icon and launch background artwork.
- Added native splash dismissal after a submitted normal game frame to hand presentation from launch artwork to the game.
- Normalized Retro font scale and baseline.
- Pause actions: Back, Return to Title and Quit Game. Return to Title retains its unsaved-progress confirmation. Quit remains available; error-free exit is not claimed.
- RGB24 preparation failure falls back to black rather than interpreting incompatible 15-bit image data.
- Public save states remain disabled with Coming soon-ish*. Normal memory-card saves remain available. The next build is planned to remove the save-state menu entirely.

Battle Overhaul 2.0, HD Day2–6 pictures and a sharper choice-selection finger are planned work, not features of this release. Specific enemy-to-Aya lighting and complete effect coverage remain unresolved. Existing enhanced particle effects require Hybrid/New mode; Original retains original presentation.

## Updating and game data
Back up the entire active PS5GameTest/user folder before a store update, including normal memory cards and settings. Store updates can replace app-local files. Preserve the two-folder PS5GameTest plus parasite-eve layout and stable title ID PEVG00022. Supply your own compatible discs at parasite-eve/discs/disc1.bin and disc2.bin, or use supported existing asset paths. Do not assume a generic store PEVG00022-folder instruction describes this package's actual layout.
