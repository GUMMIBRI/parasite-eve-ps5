# Public source policy

The public build recipe requires PE_NATIVE_PUBLIC_RELEASE=ON and defines PE_NATIVE_PUBLIC_RELEASE=1. The Save states tab remains grey with Coming soon-ish*; experimental checkpoint work is disabled before registration/preflight/hash/capture/load. Normal memory-card saves are unchanged. Private builds may use the source default0. This is a source export, not a new public binary or console qualification.
