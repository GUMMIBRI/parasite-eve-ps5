# PS5 native source export — 3F40

This source-only contribution refreshes the selected PS5 Game Test source from game-test-standard-share-owned-20261102-a1 (3f40867c6d3263ff5e741086b3eddfd5a7895b197e0a8ed324321acd2e084339). It does not add a separate PC implementation or claim a PC build. Many rendering, menu and platform features are guarded by PE_PS5_GPU_NATIVE. PS5-REUSE-MAP.json distinguishes reusable mechanisms from platform integration.

The pinned game, PsyZ and SDL archives in manifest.json reconstruct 210 changed normalized source records, 40 SDL mirrors and 80 digest-bound support/state inputs. Run node prepare-source.cjs <archive-directory> <fresh-output>. All seven selected shader headers were reproduced with the pinned compiler. Run generate-all-shaders.cjs with that compiler to repeat this check. The build recipe explicitly selects GAME_TEST and ChangedCohorts ON; it regenerates the public source cohort from actual prepared inputs. Public cohort generation and a complete public build remain pending. No PC, console or gameplay execution was performed for this export.

The selection includes the source-bank font reference correction and independent Original / Modern (IBM Plex) / Retro (Chakra Petch) choices; static RGB24 title-screen movie ownership retirement; six native Graphics, Mods, Save states, Cheats, Controls and System tabs with the complete registered hierarchy; fresh cheats Off with persisted choices preserved; and observed checkpoint failure diagnostics. These are source changes, not proof of title readability or successful checkpoints. Rendering retains bounded source-derived particle effects and the existing presentation-only interpolation path; no later orb/flame work is included.

Checkpoint source is experimental PM29 with exact typed owners, same-launch/room/source/settings restrictions and strict rejection. Native resident 85–107 and selected 115/117/118 and common 0–7 owners have bounded source contracts; unsupported variants including Point control 1 and unknown scratch roots still reject. This is not arbitrary-frame, cross-process or general battle save support. Actual reported mod-host rejection is not represented as a successful capture. Normal card saves remain separate.

Movie proportions with blurred sides, optional stretch and opt-in cleanup mode 3 remain independent choices. Native font and rendering improvements do not automatically enable on ordinary PC builds. Requested presentation rate is not a claim of unique interpolated frames or performance.

No original game assets, private background/character indexes, owner settings, saves, logs, credentials or compiled binaries are included. The private preferred factory TOML is omitted. Embedded licensed font source data is intentionally retained with SIL OFL notices; no private font assets are substituted. The optional private test-kit fingerprint is removed: without PE_NATIVE_TESTKIT_SHA256 the optional source must be absent, otherwise seeding fails closed without writing. A caller may provide a 32-byte initializer for their own authorized seed. No seed or private fingerprint is published.

Public native pack admission uses the generated no-pack sentinel and rejects without an owner-provided index. The selected CRT shim is supplied as source and rebuilt, not shipped as a binary. support/unsupported.c and the link template are existing public adapters rather than claims of private binary identity. The opaque SDL I/O override uses public stdio calls; it does not replace system modules. Dependency pins, licenses and incomplete Mesa/toolchain build-closure limitations remain in DEPENDENCIES-PINS-LICENSES.json. Preserve all upstream copyright and license notices. Historical proof files describe older exports only; CURRENT-* records describe this preparation.
