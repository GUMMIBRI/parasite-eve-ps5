Parasitic Event Revisited — START HERE

1. Open this installed app folder (the one containing eboot.bin).
2. Open parasite-eve-data/discs. Create these folders if missing.
3. Copy your own compatible North American disc images there as:
   disc1.bin
   disc2.bin
4. Start the app when copying has finished.

CORRECT LAYOUT
  eboot.bin
  sce_sys/
  parasite-eve-data/discs/disc1.bin
  parasite-eve-data/discs/disc2.bin
  user/  (your saves and settings; preserve this folder)

The download contains NO game discs. Keep both discs together. Do not nest
another app folder or another parasite-eve-data folder inside these folders.
Recomp users: the data folder belongs INSIDE this app folder; a separate
folder beside the app may not be installed.

IF IT DOES NOT START
Missing files: check the two filenames and layout above.
Incomplete data: both files must be present, readable and nonempty.
Access/read error: the files were not readable; do not delete saves or change
permissions blindly. Check that copying finished and the storage is available.
Existing configured paths: saved/imported explicit paths override automatic
folder discovery. Correct those paths if you moved their files.
Multiple external copies: keep one complete data location or deliberately
configure the intended paths. Files from separate folders are not combined.
An immediate console crash is not proof of an asset-folder problem.

UPDATING AND SAVES
Back up this entire user folder and personal files before updating. Preserve
discs, mods and use-existing-config.txt. Do not replace them with empty folders.
Active saves: user/memory-cards/bu00 and user/memory-cards/bu10 inside this app.
USB /saves is optional MANUAL IMPORT STAGING, not the active save folder.
No automatic import or migration. Keep original save filenames and backups.
Whole PS1 .mcr/.mcd cards are not individual native-PC saves; do not rename them.

Existing working external setups remain supported. Close the game before
moving files, then restart it. See DATA-SETUP.txt for advanced layouts.
