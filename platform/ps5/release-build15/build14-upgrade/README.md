# Build14 source overlay

Source preparation for Beta0.2.1(Build14), planned tag `v0.2.1-beta`, content version `01.000.014`. Manager owns release selection, Git and publication.

Starting with the public Build13 recipe, prepare its pinned source archives in a fresh directory. Apply its optional generic choice adapter and regenerate its seven shader headers using its pinned compiler **before** this overlay; those operations validate their Build13 parents. Then run:

```
node apply-build14.cjs <prepared-Build13-with-choice>
```

The manifest requires all 20 authored-source preimages before writing anything, and checks each overlay postimage. Support files remain portable templates using the parent recipe's `@ROOT@` and `@BASE@` substitution. No generated owner input, owned pack, source cohort, local path, binary receipt, original image or fingerprint is supplied. Existing public dependency and license notices remain applicable, including IBM Plex OFL and stb notices. Retain the complete parent recipe and notices.

The title change obtains identities at runtime only after the original title bank's successful load and completion poll. It checks workspace bounds, exact bank offsets, all five image dimensions, live node-pool ownership, original producer image pointers and draw dimensions. Overlapping disc writes and disc rebinding retire the owner and every node binding. Each admitted draw rechecks the loaded image identity. Plex generates the complete labels; Original/Retro, copyright and the selection oval retain their original paths. No private initializer or original pixel fingerprints enable this correction.

Build13 Combat13 and SLIM logic, normal cards, stable IDs, P5/Plex rendering and the generic choice fallback are retained. Build14 removes native disc installer launch support and SaveStates UI. PointSprite source consumers and the required caller-input omission are preserved.

**Binary preparation is blocked:** the existing caller-input generator embeds the omitted PointSprite instruction table. A public executable cannot use that generated initializer while satisfying the owner's explicit prohibition on original input bytes in the binary. The manager must resolve the proposed validated runtime caller-file change. Do not run the unchanged Build13 build recipe or package an executable from the private candidate as this public update. The public source cohort generation step also needs replacement with a public constant because SaveStates is unavailable and private source identities must not enter the executable.

Source reconstruction and SDK-header compilation of the two title-boundary translation units succeeded. No full SDK link, conversion, SELF, five-file binary update or gameplay validation is claimed by this overlay. Independent privacy review remains pending.
